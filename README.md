# Importadora de Bazar

> Tienda online moderna especializada en la comercialización y distribución de artículos de bazar, diseñada para ofrecer una experiencia de usuario fluida, atractiva y optimizada para motores de búsqueda.

---

## 🚀 Tecnologías Utilizadas

Este proyecto fue desarrollado empleando las siguientes herramientas y tecnologías web:

*   **HTML5:** Estructura semántica del sitio web.
*   **CSS3 & SASS:** Estilos avanzados, modularización y mantenibilidad del diseño.
*   **Bootstrap:** Framework CSS para garantizar un diseño responsivo y adaptativo.
*   **JavaScript:** Interactividad, lógica del cliente y dinamismo en la tienda.
*   **SEO:** Optimización en motores de búsqueda para mejor visibilidad y posicionamiento.
*   **Git y GitHub:** Control de versiones y colaboración en equipo.

---

## 👥 Metodología y Colaboración

Durante el desarrollo de este proyecto se implementaron buenas prácticas de control de versiones y trabajo colaborativo:
*   **Feature Branching:** Creación de ramas específicas (`feature/...`) para el desarrollo de cada funcionalidad o sección de forma aislada.
*   **Uso de Issues:** Seguimiento de tareas, errores y propuestas de mejora organizadas mediante incidencias.
*   **Pull Requests:** Revisiones de código e integración formal de cambios a la rama principal una vez aprobadas las funcionalidades.

## 💻 Cómo Empezar

Puedes acceder o visualizar el proyecto de las siguientes maneras:

*   **Opción 1 (Recomendada):** Visita el enlace en la sección **"About"** (Acerca de) de este repositorio para ver el sitio desplegado en producción.
*   **Opción 2 (Local):** Clona el repositorio en tu máquina local y ejecuta el archivo `index.html` en tu navegador de preferencia:
    ```bash
    git clone https://github.com/iarispe/importadorBazar.git
    ```
